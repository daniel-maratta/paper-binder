  - Tenant-host suite (`e2e/tenant-host.spec.ts`): **2/3 passed**. `Should_ExerciseAdminNormalForbiddenAndLogoutTenantFlows_InBrowser` fails at `page.getByLabel("Tenant admin").check()` (`e2e/tenant-host.spec.ts:59`) with a 30s timeout — the locator is never found.
    - **Root cause identified by code inspection**: `tenant-binder-detail-route.tsx` line 31 explicitly filters `TenantAdmin` out of the binder-access-policy's selectable roles (`binderPolicySelectableRoleOptions = roleOptions.filter((role) => role !== "TenantAdmin")`), and the panel copy states "Tenant admins always retain access" (line 238). There is no "Tenant admin" checkbox to check — this is intentional product behavior, not a rendering bug.
    - **Classification: test defect (stale test expectation)**, not a product regression. The test was written against an assumption that no longer matches the implementation.
    - Not fixed here (baseline is recording-only); assigned to `T-0045` for correction of the test.

## Responsive Viewport Matrix (T-0039)

`T-0039` established and executed a 5-viewport sweep (390×844, 768×1024, 1100×800, 1280×832, 1440×900) across public and authenticated routes/states, using a new reusable script (scripts/capture-responsive-qa-screenshots.ps1, added on that branch). That work is **complete but lives on branch review/v1.1.0-responsive-t0039, not yet merged here**. Summary (see `T-0039`'s task file for full detail):

- Found and fixed a confirmed, release-relevant defect: the authenticated shell rendered broken (sidebar stacked full-width above content instead of beside it) for any viewport in the 1024–1180px range, due to a CSS breakpoint (1180px) drifting from the JS-driven mobile/desktop shell threshold (1024px). Fixed by aligning the CSS threshold to 1023px.
- Deferred (not fixed, tracked in `T-0041`): the Binders-table ID copy-chip wraps character-by-character at narrow (<420px) widths; needs the same mobile-card treatment already used on the Users page.
- Deferred (not fixed, tracked in `T-0045`): `TenantImpersonationBanner` component is defined but never rendered.
- This branch (review/v1.1.0-baseline) has **not** incorporated the T-0039 fix; the shell-grid defect described above is still present here until the branches reconcile.
