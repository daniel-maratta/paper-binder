# PaperBinder legal notices

PaperBinder is a public demonstration project and hiring portfolio piece operated by Daniel Maratta. It is not a production SaaS service. Do not use it for confidential, sensitive, regulated, proprietary, personal, medical, financial, credential, or otherwise important real business information.

Use these notices to understand how the public demo operates before creating or using a temporary workspace.

- [Privacy Policy](/privacy) explains what the demo collects, including basic usage analytics, how temporary workspace data behaves, and how to contact the operator about data questions.
