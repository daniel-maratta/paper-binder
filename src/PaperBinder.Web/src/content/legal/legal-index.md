# PaperBinder legal notices

PaperBinder is a demonstration and hiring artifact operated by Daniel Maratta. It is not a production SaaS service and should not be used for confidential, sensitive, regulated, proprietary, personal, medical, financial, credential, or otherwise important real business information.

Use these notices to understand the current public demo posture before creating or using a temporary workspace.

- [Privacy Policy](/privacy) explains what the demo collects, how temporary workspace data behaves, and how to contact the operator about data questions.
- [Terms of Use](/terms) explains permitted use, demo-only status, temporary workspace behavior, ownership, disclaimers, and limits.
- [Cookie Notice](/cookies) explains the current strictly necessary auth and CSRF cookie posture, plus Turnstile challenge behavior.

These documents are drafted for the current PaperBinder v1.1.1 legal-readiness work and require owner approval before public release.
